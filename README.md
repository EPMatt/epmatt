# Hi, I'm Matteo 👋

I build software and help teams scale the infrastructure behind it.

I'm a platform engineer and tech founder based in Zurich 🇨🇭, working across
cloud infrastructure, cybersecurity, DevOps, and developer experience.
I've founded startups, built products from scratch, and helped other founders
turn their ideas into real businesses.

- ☁️ **Infrastructure & delivery:** I help teams build and operate reliable
  cloud infrastructure, automate complex CI/CD pipelines, and manage cloud
  costs. I work with AWS, GCP, Pulumi, and GitHub Actions.
- 🛠️ **Developer tooling:** I build internal tools in TypeScript and Go,
  with a current focus on agent workflows and observability across
  infrastructure, product metrics, and cloud spending.
- 🏠 **Open source & home automation:** I'm the founder and maintainer of
  Awesome HA Blueprints, a community-driven collection of reusable
  Home Assistant automations.

Away from the keyboard, you'll find me at a piano 🎹 or behind a camera 📷.
